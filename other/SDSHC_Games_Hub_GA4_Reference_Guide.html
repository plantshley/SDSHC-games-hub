🌷Sample Queries You Can Run

Once you have data in Google Analytics, try these queries in Explore mode:

🎮 "Which games are most popular?"
Dimension: game_id
Metrics: Event count
Filter: Event name = game_start
Visualization: Bar chart, sorted by count
👥 "Are visitors mostly playing solo or multiplayer?"
Dimension: player_count
Metrics: Event count
Filter: Event name = game_start, mode = advanced
Result: Distribution of 1, 2, 3, 4 player sessions
👶 "Which age group visits most in Kid Mode?"
Dimension: tier
Metrics: Event count
Filter: Event name = grade_tier_select
Result: Counts for sprouts (Pre-K-2nd), meadow (3rd-5th), guardians (Middle+)
🏆 "Kid Mode vs Advanced Mode — which gets more traffic?"
Dimension: mode
Metrics: Event count
Filter: Event name = mode_select
Visualization: Pie chart
🚪 "How many sessions end from idle timeout?"
Dimensions: mode, last_screen
Metrics: Event count
Filter: Event name = idle_timeout
Result: Shows where users walk away — useful for identifying boring screens
❌ "Which games do people quit most often?"
Dimension: game_id
Metrics: Event count
Filter: Event name = game_quit
Compare with: game_start counts for the same game_id to get quit rate
📚 "Which topics are most popular in Trivia / Connections / Field Guide?"
Dimensions: game_id, topics
Metrics: Event count
Filter: Event name = topic_select
Result: Most-chosen content topics per game
🔁 "Are players asking to play more rounds in Word or Worm?"
Dimension: rounds_so_far
Metrics: Event count
Filter: Event name = play_more_rounds
Result: How many times "Play More" is used and at what round count
🌙 "Does anyone use light mode?"
Dimension: theme
Metrics: Event count
Filter: Event name = theme_toggle

💐Custom Parameters by Event Type

Core Events

🎯mode_select Event

Fires when a visitor chooses Kid Mode or Advanced Mode on the intro screen.

mode The selected mode: kid or advanced

🕹️game_start Event

Fires when a game is launched (both Kid and Advanced modes).

game_id Game identifier (e.g., adv-spin-wheel, soil-cake, trivia-blitz)
mode kid or advanced
tier Kid mode grade tier: sprouts, meadow, or guardians (null for advanced)
player_count Number of players (1-4). Always 1 for kid games.

🏆game_complete Event

Fires when a game is finished normally (all rounds completed).

game_id Game identifier
mode kid or advanced
player_count Number of players in the session
score Highest player's score at completion

🚪game_quit Event

Fires when a player quits a game mid-play (via Quit button or confirmed Back).

game_id Game identifier
mode kid or advanced
rounds_played Number of rounds/questions completed before quitting

⏰idle_timeout Event

Fires when the idle timer expires and resets to the intro screen.

mode Mode at timeout: kid, advanced, or intro
last_screen Hash route at timeout (e.g., advanced/game/adv-jeopardy/0)

Secondary Events

👶grade_tier_select Event

Fires when a kid mode grade tier is selected.

tier sprouts (Pre-K-2nd), meadow (3rd-5th), or guardians (Middle+High)

📚topic_select Event

Fires when topics are chosen in games that offer topic selection (Spin Wheel, Trivia Blitz, Field Guide, Connections).

game_id Game identifier
topics Comma-separated list of selected topic names (e.g., Nitrogen Cycle, Conservation, Soil Biology)

🔁play_more_rounds Event

Fires when a player taps "Play More Rounds" in Word or Worm? to extend the game.

game_id Always adv-word-game
rounds_so_far Number of rounds completed when "Play More" was tapped

🌙theme_toggle Event

Fires when the dark/light theme toggle is tapped in any advanced game screen.

theme The new theme: dark or light

🌸All Unique Parameters (Alphabetical)

Every parameter you can register as a custom dimension or metric:

game_id Game identifier (e.g., adv-spin-wheel, soil-cake)
last_screen Hash route when idle timeout fired
mode kid, advanced, or intro
player_count Number of players (1-4)
rounds_played Rounds completed before quitting
rounds_so_far Rounds completed when Play More was tapped
score Highest player score at game completion
theme dark or light
tier Kid mode grade tier (sprouts, meadow, guardians)
topics Comma-separated selected topic names

⭐Recommended Custom Dimensions to Register

Prioritized list based on usefulness (you can register up to 50 in GA4):

💖High Priority (Register These First)

game_id Which games get played most — the #1 insight HIGH
mode Kid vs Advanced audience split HIGH
player_count Solo vs group play patterns HIGH
tier Age group distribution in kid mode HIGH

🌟Medium Priority (Good Insights)

topics Which content topics are most popular MEDIUM
score Engagement depth — register as a custom metric (numeric) MEDIUM
rounds_played How far players get before quitting MEDIUM
last_screen Where idle timeouts happen MEDIUM

🌱Low Priority (Nice to Have)

theme Dark/light mode preference LOW
rounds_so_far Word or Worm extension tracking LOW
Pro Tip: Start by registering the 4 High Priority dimensions. These give you the most actionable insights about audience, game popularity, and play patterns. Add Medium Priority dimensions once you have a week or two of data flowing to dig deeper into content preferences and engagement.

🎀How to Register Custom Dimensions

  1. Go to Admin (gear icon in bottom left of Google Analytics)
  2. In the Property column, click Custom definitions
  3. Click Create custom dimension
  4. For each parameter:
    • Dimension name: Use a friendly name (e.g., "Game ID")
    • Scope: Select "Event"
    • Description: Add a brief description
    • Event parameter: Enter the exact parameter name (e.g., game_id)
  5. Click Save
  6. Repeat for each parameter you want to track
For numeric values like score, player_count, rounds_played, and rounds_so_far: register these as Custom Metrics (not Dimensions) so you can calculate averages, sums, and ranges in Explore reports.
Important: Custom dimensions can take 24-48 hours to start collecting data. Events sent BEFORE you create the dimension won't be retroactively updated, but all new events will include the dimension automatically.
