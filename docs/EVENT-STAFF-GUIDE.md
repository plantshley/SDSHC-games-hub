## What the hub is

Two modes, chosen on the opening screen:

- **Kid Mode** — pixel-art games for Pre-K through middle/high school. No teams, leaderboard, or additional setup required to play.
- **Advanced Mode** — sleek, modern games for high school and college. **This is the mode with Admin controls, events, teams, and the leaderboard.** Everything in this guide is about Advanced Mode.

**Advanced Mode has 6 games, all 1–4 players:**

| Game | What it is |
|---|---|
| ☉ Spin the Wheel | Spin, pick a category, answer soil science questions |
| ⚡︎ Trivia Blitz | Timed multiple-choice rounds. Choose from **Topic Mode** or **Endless Shuffle** |
| ✦ Soil Jeopardy | Category grid with point values and Daily Doubles |
| ℵ Word or Worm? | Wheel-of-Fortune style game; guess soil terms letter by letter |
| ☘ Field Guide | Identify SD plants, crops, wildlife, soils, and equipment from photos + hints |
| ⧉ Conservation Connections | Sort 16 tiles into 4 hidden groups |

There is also a "hidden" game in progress — tap the 𖧧 button to check it out! 👀

All six count equally toward the leaderboard. Scores are **normalized**, so a strong Jeopardy run (thousands of raw points) is worth about the same as a strong Connections run (tens).

Games have no sound effects, run fully offline once prepped, and never need the internet to *play*. The internet is only used to save scores to the shared leaderboard (which also queues safely offline).

Access the leaderboard from the **trophy icon button (🏆)**, and from there view the Admin panel via the **Admin** button in the bottom right. View game instructions on each game's introduction screen via the **(?)** button next to the title. Switch between light and dark mode with the **☾ / ☀︎** toggle.

## Choose your event shape

**"Team" may not mean the same thing at every event,** and there are three primary anticipated event shapes. Pick one of these three before you set anything up — they require different prep, approvals, and cleanup.

| | **A. School vs. School** | **B. Class Teams** | **C. One School, One Team** |
|---|---|---|---|
| **Who's coming** | Several schools | One classroom | One school |
| **A "team" is** | Each school | Each small group of students | The whole school, with individual students or groups as "players" |
| **A "player" is** | An individual student (use their name) or a group of students (use the group/team name, or a representative's name) | An individual student (use their name) or a group of students (use the group/team name, or a representative's name) | An individual student (use their name) or a group of students (use the group/team name, or a representative's name) |
| **Who creates teams** | You (beforehand) or Students | You (beforehand) or Students | You (beforehand) |
| **How many teams** | 2–10+ | 2–8 | 1 |
| **Approve for event?** | Yes, each school | Yes, each group | Yes |
| **Approve statewide?** | Yes, each school | **No** | Yes |
| **After the event** | Nothing | Merge the groups into the school | Nothing |
| **Competition happens** | Between schools, live | Between groups, live | Statewide, over time |

See [the two approvals](#the-two-approvals) for details on approving for **event** vs. **statewide**.

### Path A — School vs. School

Two or more schools at the event, each trying to gain points for their school. (Ashley can do steps 1–3 if you let her know beforehand.)

1. **Before the event, online:** Advanced Mode → Leaderboard (🏆) → Admin → Events → select the **"Manage teams"** button visible on your scheduled event. Then add each school by name, giving each a distinct color pair. Tap **"+ Add team"** for each.
2. Also tap **"Approve statewide"** on each, so the points reach the All-Time leaderboard. Teams you add here are auto-approved for the event.
3. **Students** pick their school from the dropdown. No typing.
4. **After:** nothing to do. Check for duplicates if you ran multiple devices offline.

Different players on one device can be on different teams. A head-to-head between 2, 3, or 4 schools can keep energy high!

### Path B — Class Teams (one classroom, groups compete)

One school, students split into small groups that compete against each other at the event.

If you choose to pre-create and approve the teams (or have Ashley do it) rather than have the students create their own team names live, the Team dropdown on each game's intro screen will list these teams for students to pick from. If not, each group can create a name by hand, which will arrive as *pending* on the admin page, and **the event leaderboard stays empty until you approve each one.**

If you pre-create teams, here are some recommendations:

1. **Name the groups with the school as a prefix (or suffix):** `Lincoln – Table 1`, `Lincoln – Table 2`, … See the warning below.
2. **Beforehand, online:** Advanced Mode → Leaderboard (🏆) → Admin → Events → select the **"Manage teams"** button visible on your scheduled event. Then add each group by name, giving each a distinct color pair. Tap **"+ Add team"** for each. They will be automatically approved for the event. Do **not** approve them statewide.
3. **Event day:** students pick their group from the dropdown, and the event leaderboard fills up live as they play.
4. **After:** [merge the groups up into one school team](#merging-class-teams-into-a-school-team) so the school gets combined credit on the All-Time board.

> ⚠️ **Team names are global, not per-event.** The app looks a team up by name across the *entire* database, not just your event. If you create a bare `Table 1` today for Lincoln and someone creates `Table 1` next month for Brookings, **the two schools' scores merge together.** (Note: capitalization and extra spaces are ignored, so `table 1` and `Table  1` are the same team — but spelling is not.)

If you *do* want students naming their own groups during the event, you must keep the admin panel open on a second device to approve each group as students enter them. If offline, you must approve each group on the student's device in order for them to see their team on the leaderboard, though scores will still save silently while the team is *pending*.

### Path C — One School, One Team

Everyone at the school plays under a single team name, pooling every point.

1. **Before, online:** add the school as one team for your scheduled event via **Manage teams** on the Admin panel. (Be sure to also tap **"Approve statewide"**.)
2. **Students** pick the school every time, and type their own (or group's) name in the player field.
3. **After:** nothing.

**Note:** with one team, the event leaderboard has exactly one row, so there is no in-room competition to watch. This shape is for driving the school up the **All-Time** board, not for a competitive classroom. If you want both, run Path B and merge afterward — you get the live competition *and* the pooled statewide score.

> 🔒 **IMPORTANT: Stop the browser from remembering the admin password (one time, per device)** if you access the Admin panel on the device that students will use. The first time you sign in, Edge or Chrome will pop up **"Save password?"** — click **Never**. If it already saved it, delete it so it can't auto-fill for whoever opens the panel next:
> - **Edge:** Settings → **Profiles → Passwords** → find the site → **⋯ → Delete**. Then turn **"Offer to save passwords"** off.
> - **Chrome:** Settings → **Autofill and passwords → Google Password Manager** → the entry → **Delete**. Then turn **"Offer to save passwords"** off.
>
> On a shared event device, a saved-and-autofilled password lets a student click straight through the sign-in screen — deleting it keeps the panel actually locked.

## Before the event — device prep

**Do all of this at home, on good Wi-Fi, on the exact device you're bringing.** If using a computer or device at the event/school/classroom itself, you can **skip steps 1 and 2** and just use the website link. However, this runs the risk of the URL being blocked by school Wi-Fi or other unforeseen issues. **Step 3** can also be done separately on a different device prior to the event.

### 1. Install the app (once per device, NOT per event)

1. Open **Microsoft Edge** or **Google Chrome** and go to https://plantshley.github.io/SDSHC-games-hub/
2. Look at the far right of the address bar for an **"Install"** or **"App available"** icon. Click it and confirm.
3. You now have a desktop/Start Menu shortcut. **Use that shortcut from now on**, not the browser tab.

Installing gives you a full-screen app with no URL bar, and — more importantly — it's what lets the app run with no internet. You only need to do this once for the device unless the app shortcut gets uninstalled.

### 2. Cache the games for offline

The app downloads its code automatically, but the ~107 MB of photos, files, and diagrams are fetched on demand. Force them all down prior to the event:

1. Open the installed app **while online**. Let it sit a few seconds — it auto-updates in the background.
2. Go to **Advanced Mode → Leaderboard (🏆) → Admin** (or type the admin URL directly).
3. Enter the **admin password**. (Ask Ashley — it's one shared password.)
4. Scroll to **Offline readiness** → tap **"Cache for offline"**.
5. Wait for **"✓ All assets cached — ready to go offline."**

> ⚠️ **Re-do this after every app update.** A new version means new files, and the old cache no longer covers them. Tapping the button again when already cached is harmless and fast.

> 🔒 **IMPORTANT: Stop the browser from remembering the admin password (one time, per device).** The first time you sign in, Edge or Chrome will pop up **"Save password?"** — click **Never**. If it already saved it, delete it so it can't auto-fill for whoever opens the panel next:
> - **Edge:** Settings → **Profiles → Passwords** → find the site → **⋯ → Delete**. Then turn **"Offer to save passwords"** off.
> - **Chrome:** Settings → **Autofill and passwords → Google Password Manager** → the entry → **Delete**. Then turn **"Offer to save passwords"** off.
>
> On a shared event device, a saved-and-autofilled password lets a student click straight through the sign-in screen — deleting it keeps the panel actually locked.

### 3. Create and approve your teams

Follow the recipe for [your event shape](#choose-your-event-shape). Do this **online**, and do it **once**, not once per device. Teams live in the cloud and every prepped device will see them.

### 4. Warm the leaderboard

Back out to **Advanced Mode** and tap the **trophy icon 🏆** once while still online. This pulls the current teams and scores into the device's local cache so the leaderboard isn't empty offline. Seeing real teams and any existing scores indicates it worked.

### 5. Confirm the device joined the event

The device should auto-join when the event opens, but it's worth double-checking just before or at the venue/school:

1. Open **Advanced Mode**. If your event is open, the first screen is **"How do you want to play?"** with **Event: *Your Event Name*** under the heading. That's the device confirming it joined.
2. See a **"Which event are you at?"** list instead? Two or more events are open. Either pick yours, or (cleaner) go to **Admin → Events** and **End** the stale one so only yours remains.
3. See the game grid with **no** play prompt? No event is open yet. If you **scheduled** yours for later, that's expected — it'll open itself when the start time arrives. To open it right now instead, go to **Admin → Events**, find yours, tap **"Open now"**, then reopen Advanced Mode.

You can also manually override which event is active: **Admin → Active event on this kiosk → "Set kiosk to"** pins a device to a specific event by hand.

### Pre-event checklist, per device

- [ ] App is **installed** (opened from the desktop shortcut, not a browser tab)
- [ ] Admin → Offline readiness shows **"✓ All assets cached"**
- [ ] Trophy icon shows real teams/scores (not empty, not "Loading…")
- [ ] Your teams appear on the event roster marked **✓ Event**
- [ ] Opening a game's intro screen shows those teams **in the Team dropdown**
- [ ] Device is **charged**, and you have the charger
- [ ] You know the admin password
- [ ] If running the event on Wi-Fi or hotspot, have your own separate device ready with the Admin page open or pinned
- [ ] Just before or at the venue, Advanced Mode shows the **"How do you want to play?"** prompt naming your event (proof it auto-joined)

## Bringing more than one device

If you would like to have live, synced competitive play — leaderboard updates between devices, and live Admin changes/approvals showing on each device — each device **must** be online via Wi-Fi or a mobile hotspot.

- **Events and teams are shared** through the cloud, so they only need to be created once.
- **Every device auto-joins the open event;** there's no per-device event step. Each device still needs its own [offline prep](#before-the-event--device-prep) (install + cache), and it's worth double-checking the device clock to make sure it's accurate. (You can skip install/cache on a device used at the venue, noting the risks.)
- **If pre-creating the teams,** do it once on any device, online, before the event. Then every device shows the same dropdown to pick from.

Offline play still works, but each device will only see its own local leaderboard and score updates — not how the scores are tallying for a team on a separate device. You also cannot approve teams from a separate device if the students create them offline during the event; if needed, you must log in to Admin on the same device and approve them. To avoid this issue, simply pre-register teams via **(🏆) → Admin → Events → Manage teams** for your scheduled event ahead of time (or have Ashley do it).

## Setting up an event yourself

Go to **Admin** (trophy icon 🏆 → "Admin" button at the bottom of the leaderboard) and sign in. Or, bookmark/pin the direct link for easy access (https://plantshley.github.io/SDSHC-games-hub/#advanced/admin).

### Create the event

In **"Active event on this kiosk"**, bottom row:

1. Type an **event name**. Students see this as their leaderboard tab, so name it something identifiable, like `Brookings Middle School Visit`, not `event3`.
2. Choose **"Start now"** or **"Schedule for"** + a date/time.
3. Tap **"Create event"**.

| Choice | What happens |
|---|---|
| **Start now** | Event opens immediately. **Every prepped device auto-joins it** when it enters Advanced Mode — this one included. |
| **Schedule for** | Event is created with status `scheduled`. It stays dormant until its start time, then **opens itself automatically** — on every device, no sign-in needed. It just isn't joinable (or in the "Set kiosk to" dropdown) *before* that time. |

> **Scheduling opens the event for you** at the time you set. Two things to know: (1) each device opens it using **its own clock**, so a badly-set device clock shifts when it flips open; (2) to open a scheduled event *early*, tap **"Open now"** on its row. If you'd rather not think about timing, you can use **"Start now"** on the morning of.

### Managing events

The **Events** section lists everything with a status badge that's **derived from the clock**. A scheduled event whose time has passed shows `open`, and an event past its end time shows `ended (auto)`.

| Status | Meaning | Actions |
|---|---|---|
| `scheduled` | Created for later; opens itself at its start time | **Manage teams** (pre-create teams), **Open now** (opens early), **Ends** time, Delete |
| `open` | Running — accepts scores | **End**, **Ends** time, Delete |
| `ended` | Finished (by hand or aged out), still on the leaderboard | **Reopen**, Delete |

- **Manage teams** lets you pre-create and approve teams for the scheduled event (not available for `open` events).
- **Open now** opens a scheduled event *ahead* of its start time. You don't need it at the scheduled time itself — it opens on its own then.
- **End** closes the event now. If it was active on your device, that's cleared. Other devices notice and update next time they're online.
- **Reopen** un-ends it (ended by accident, or a multi-day event) and pushes its end time back out so it doesn't immediately re-close.
- **Ends** — each running/scheduled row has an editable end date/time. This is when the event closes itself.
- **Delete** ⚠️ **permanently destroys the event *and every score tagged to it*.** No undo. When an event is simply over, use **End**.

> **Events close themselves so nothing stays joinable forever.** Every event auto-ends **24 hours after it starts** by default. For a longer or multi-day event, edit the **"Ends"** date/time on its row to push that out. You can still **End** it early at any time, and a row that closed itself shows `ended (auto)`.

## Running the event — what students see

![Games Hub screen flow: the Opening Screen splits into Kid Mode (grade select → game select → game intro → play) and Advanced Mode. In Advanced Mode, the number of open events decides what happens — one open joins automatically, more than one asks "Which event are you at?", none open behaves the same as Casual Play. Both then reach "How do you want to play?", which splits into Team Play (team roster → game select → game intro, type player name and select team; team scores save to the event and All-Time leaderboards) and Casual Play (game select → game intro, type player name, no teams; player scores are recorded in-game but reach no leaderboard).](games-hub-screen-flow.svg)

Only the **Team Play** path shows a Team dropdown and puts scores on a leaderboard. Casual Play and "no event open" look identical to the student — a name field, no team, nothing tracked publicly.

> **A "player" doesn't have to be one student.** In [Path B](#path-b--class-teams-one-classroom-groups-compete) each player slot can be a whole group huddled around the device: they pick their group from the Team dropdown and put the group's name (or a representative's) in the name field.

### The play-mode prompt

If exactly one event is open, the device joins it automatically and the first screen after Advanced Mode is **"How do you want to play?"**, naming the event. If several events are open, that screen first asks **"Which event are you at?"** — pick yours, then choose Team or Casual.

- **Team Play** — scores roll up to a team. Goes to the roster screen next.
- **Casual Play** — no team tracking. The team field is hidden everywhere, and scores are recorded but **never appear on any leaderboard.**

This Team vs. Casual Play choice lasts for the browser session, not forever. After **10 minutes** idle the app returns to the opening screen, which clears the choice — so the next group is asked fresh. If players want to switch between play modes, tap **Back** to the opening screen and re-select Advanced Mode.

> **Picked the wrong event?** When several events are open, the "Which event are you at?" picker re-appears on every fresh entry — so just tap **Back** to the opening screen and re-enter Advanced Mode to choose again.

### The roster screen (Team Play only)

Students type a school or team name, optionally pick two accent colors, and tap **"+ Add team"**, then **"Start playing →"**.

- Autocomplete here suggests teams **approved statewide** from past events, so returning schools don't get duplicated.
- A brand-new name creates the team as **pending**, on the event roster as **pending**.
- Rude names are blocked on the spot.
- Reachable later via **"Manage roster"** in the game-select header.

**If you pre-created your teams, students should skip past this screen** — just tap "Start playing →". They'll pick their team on the game intros instead.

### Player + team entry on each game

Every game's intro has a row per player (up to 4): a **name**, and in Team Play a **Team** dropdown.

- The dropdown lists **only teams approved for this event.**
- Students can still **type** a team that isn't listed. It resolves correctly and tags their scores, but Admin will have to approve.
- After typing, a marker appears: **"✓ on roster"** or **"↻ awaiting approval"**.
- **A "Player" can be a group, not just one student:** the group picks its team from the dropdown and puts the group name or a representative's name in the name field. Either way, the points go to the **team**, so what they type as the name doesn't affect the score.

### Scores

Scores save silently, and students see nothing on success. If a save genuinely fails, a small pill appears: **"Couldn't save score — tell an organizer."** Offline saves queue quietly and succeed later, so this is rare.

**Scores from a pending team are recorded correctly.** They just don't show publicly until the team is approved. Nothing is lost if you forget — approve afterward and the points appear.

### The leaderboard (trophy icon 🏆)

Two tabs:

- **Your event's name** — top-3 podium plus the rest. Only teams **approved for this event** appear.
- **All-Time** — statewide, across all events. Only teams **approved statewide** appear.

Two score columns: **Score (Normalized)**, the ranking metric, and **Raw**, the actual points earned, greyed out.

> The leaderboard footer has an **Admin** link. It's password-gated, so a curious student just hits a sign-in screen (remember to stop the device from saving the password).

## Teams: the student end vs. the admin end

Teams are created via the team roster screen, which creates them as **pending**. You can also create and approve teams for a scheduled event from the Admin page. Teams can be viewed from four places:

| | Where | Autocomplete shows | Result |
|---|---|---|---|
| **Students** | Roster screen after choosing Team Play | Statewide-approved teams | pending team + pending roster entry |
| **Students** | The "Team" field on any game's intro | Teams approved **for this event** | pending team + pending roster entry |
| **You** | Admin → Active event roster | — | Approve, rename, recolor, remove |
| **You** | Admin → Events → Manage teams | — | Create, approve, remove |

### The two approvals

These are different buttons controlling different things, and the whole [event-shape](#choose-your-event-shape) system depends on the distinction:

| Button | Where | What it unlocks |
|---|---|---|
| **Approve for event** | Admin → Active event roster | Team appears on the **event leaderboard tab**, and in the **team dropdown** on game intros |
| **Approve statewide** | Admin → Active event roster, Pending team names, or Manage teams | Team appears on the **All-Time leaderboard** |

Approving for one event does not commit a team statewide, or vice versa. Path B relies on this: class groups get **Approve for event** so they compete live, but are **not** approved statewide and instead merged into a single school team later.

### Naming — reminder for students

Points only add up if the team name matches. Capitalization and extra spaces are ignored; spelling is not. `Pierre HS` and `Pierre High` are two different teams.

And remember [team names are global](#path-b--class-teams-one-classroom-groups-compete), so a generic name like `Table 1` or `Soil Warriors` could collide with some other identical name (e.g. why prefixing with the school is recommended).

### Fixing duplicates, typos, and merges

In **Admin → All teams**, use **Rename**. **If you rename a team to a name that already exists, the two merge** — every score and roster entry moves to the surviving team. That's the intended way to clean up duplicates, and the mechanism behind the Path B merge.

**Delete** ⚠️ removes the team **and all of its scores**, permanently. Only for junk entries — never for a real team you want to tidy.

## Online vs. Offline (and blocked school Wi-Fi)

**The games never need the internet.** After the offline prep, every game runs fully from the device. The internet only matters for live Admin edits/approvals and saving scores to the shared leaderboard (live, synced competitive play across devices), and those saves queue and replay later.

### Three situations

| Situation | What to do | What happens to scores |
|---|---|---|
| **Good, open Wi-Fi** | Play via installed app shortcut (recommended) or browser with website link. | Saved to the cloud immediately. Leaderboard is live. |
| **No Wi-Fi at all** | Must play via installed app shortcut (or use hotspot). | Queued on the device, but Admin approvals and the Leaderboard do **NOT** sync across multiple devices. Syncs automatically when you get home and open the app online. |
| **Wi-Fi exists but the school blocks the site** | **Disconnect from the Wi-Fi entirely** (or use hotspot). See note below. | Same as "no Wi-Fi". |

Some schools block outside sites on their guest network. **Connected but blocked** is the worst state: the device believes it's online, so the app keeps reaching for a server it can't see. The leaderboard may not load and saves may sit there. **Disconnecting entirely** queues everything locally, and the app behaves as designed. It all syncs when you're back on a network you trust.

If you want live sync at a blocked school or no-Wi-Fi venue, use a **phone hotspot**. Otherwise, there is nothing you can do on-site if you did not prep the device at home.

### Offline rules

While offline with unsynced scores on the device:

- **Don't clear browser data / cookies / site data.** This wipes the queued scores permanently.
- **Don't uninstall the app.** Same result.
- **Don't open the site in a second browser tab** while the installed app is running. The offline database supports one tab at a time.
- **The 10-minute idle reset is completely safe.** It clears in-game progress, never the score queue.

## After the event

1. If you **ran the event offline,** get the device on trusted Wi-Fi and **open the app**. **Leave it open a minute or two** — this is when queued scores flush to the cloud. Watch the leaderboard counts climb. Do this for **every device** you ran. *(feel free to save the remaining steps for Ashley)*
2. **Merge duplicates.** Admin → All teams. If two devices were offline and students typed the school name twice, you'll see near-identical rows. **Rename** one to exactly match the other; they merge.
3. **Approve statewide** the teams that should reach the All-Time board (Paths A and C), if not done already.
4. **Path B only:** [merge the class teams into the school](#merging-class-teams-into-a-school-team).
5. **End the event.** Admin → Events → **End**. (**End**, not Delete.)
6. Tell Ashley how it went — especially if you encountered any bugs or have feedback from students.

> **As a general rule:** *Open the leaderboard once online before the event, and leave the app open online for a couple of minutes after it.* This will guarantee a clean sync.

### Merging class teams into a school team

After a Path B event, you may have something like `LHS Tulip Team` … `Soil Warriors` … `Lincoln Table 6`, each holding some points. To give Lincoln HS the combined total on the All-Time board (feel free to save this for Ashley to do):

1. Make sure every device has synced (step 1 above). **Do not merge before the scores land**, or you'll be merging incomplete totals.
2. Admin → **All teams** → find `LHS Tulip Team` → **Rename** it to `Lincoln HS`.
3. Repeat for each remaining group, renaming every one to exactly `Lincoln HS`. Each rename detects the existing team and **merges into it**, carrying its scores across.
4. When only `Lincoln HS` remains, tap **Approve statewide**.

The event leaderboard tab will now show a single Lincoln HS row instead of multiple.

> ⚠️ **Merging cannot be undone.** If you want a record of which group won, screenshot the event leaderboard before you start.

## Which device should I bring?

| Device | Verdict |
|---|---|
| **The Dell kiosk touchscreen** | Best. The hub was originally built for it. Prep once, stays prepped. 1920×1080, full-screen, touch-first. |

## Running the room

### Setting up

- **Each game serves up to 4 players (or groups) at a time,** so size teams per device to that.
- Players on **one device can be on different teams,** so you can set up competition on a single machine.
- With multiple devices, you can set up game **stations** and rotate, or have each group play on their own device.
- If unfamiliar with the games, make sure you instruct students to read the game instructions via the (?) button in the header, or go over them as a class before playing.

### Keeping energy up

- **Show the leaderboard:** tap the trophy on the device to display between games, or have it pulled up on a separate device screen (e.g. class smartboard, if not blocked by school Wi-Fi). This could serve as great motivation, seeing a team's placement change.
- Some games end with a short conservation or educational takeaway. Try to discuss before the next game or question.
- Offer prizes for winning teams to improve engagement and accuracy.

### Choosing an event shape for the setting

| Setting | Shape | Why |
|---|---|---|
| Two or more schools together | Path A + Team Play | Real competition per-event and All-Time |
| One classroom, one period | Path B + Team Play | Live competition between groups; roll up into the school after for All-Time |
| One school, chasing the statewide board | Path C + Team Play | Every point pools to the school and affects the All-Time board |
| General event, walk-up traffic | **Casual Play** | No relevant teams, but can still compete via player names for each game |
| Elementary students | **Kid Mode** | Different mode entirely, no setup |

### Things to watch for

- **Joke team names.** The filter catches profanity, not "Mr. Johnson Stinks." This is still gated by Admin's **Approve for event** — nothing reaches a leaderboard without it (or pre-create teams).
- **A group that walks away mid-game.** The screen resets after 10 minutes.
- **A student wandering into Admin.** It's password-gated; they'll see a password box and bounce, so long as you stop the device from remembering the password.

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| **No "How do you want to play?" prompt** | No event is **open** (auto-join only fires for open events) | Admin → Events → **"Open now"** on your event, then reopen Advanced Mode |
| **"Which event are you at?" keeps appearing** | Two or more events are open at once | End the stale one: Admin → Events → **End**. Only your event should be open |
| **Scheduled event isn't open at its start time** | Its start hasn't actually passed on the device's clock, or the device clock is wrong | Check the device date/time; or just tap **"Open now"** to open it immediately |
| **Event closed itself / shows `ended (auto)`** | It aged out — events auto-end 24 h after they start | **Reopen** it, then push its **"Ends"** time out for the longer window |
| **Team dropdown empty on game intros** | No teams approved **for this event** | Admin → Active event roster → **"Approve for event"** |
| **Event leaderboard stays empty during class** | Students' typed teams are still `pending` | Approve each **for the event** — or pre-create them next time |
| **A school isn't on the All-Time board** | Team isn't approved **statewide** | Admin → approve statewide |
| **Two schools' points ended up on one team** | A generic team name (`Table 1`) collided globally | Prefix names with the school. Untangling mixed scores needs per-score deletes in Admin |
| **Two rows for the same school** | Typed differently, or offline on two devices | Admin → All teams → **Rename** one to exactly match the other; they merge |
| **Leaderboard empty / "Loading…" forever** | Device never cached leaderboard data online | Go online, open the trophy, wait. Then it should work offline. |
| **Photos missing in Field Guide** | Offline cache never warmed, or app updated since | Online → Admin → Offline readiness → **"Cache for offline"** |
| **"Couldn't save score — tell an organizer"** | A genuine save failure | Note the team + game and inform Ashley. Scores usually still queue; check after syncing. |
| **Game says "screen too narrow"** | Narrower than ~600px (Field Guide: ~900px) | Rotate to landscape, or use a bigger device |
| **App won't load at the school** | Site blocked and device never prepped | Nothing on-site. Use a mobile hotspot or prep at home next time. |
| **Admin signs me out when I leave the panel** | Intended — for shared-device security, admin signs out the moment you navigate away (and when the app closes) | Sign in again when you return. Nothing is wrong |
